## 统一生成约束

- 1280 × 720 横屏移动游戏内容，不含设备边框。
- 保持圆润低多边形、玩具感比例与霞鹜文楷气质。
- 环境使用接近中性的暖白光，禁止黄褐滤镜。
- 以珊瑚色表达当前重点，以薄荷青表达下一步和正向反馈。
- 黄色只用于金币、等级星与少量奖励闪光。
- 一个页面只突出一个主要任务和一个主要按钮。
- 状态不能只依赖颜色，必须同时使用轮廓、标签、图标或形状。
