# P5 研究型玩家 · 夜间研发室 Playtest

日期 2026-08-15 · Godot 4.6.3 · 截图: /tmp/p5_{night,recipe,mkt,mktf,book,dark,brief,darkboard}.png
(注: brief/darkboard 两张远程识图服务持续 400，判定基于 6 张成功识图 + 源码/文案核对)

## 总评
实验闭环「选料 → 试做 → 反馈 → 上架/登记」成立，无阻断；扣分集中在"研究者想审计的数据"不可见。

## 发现

### 1. 困惑 · 改料后待上架分数被静默作废
- 证据: p5_recipe.png — 试做得「◎ 品质 N · 可上架」便签后，点任一原料，便签直接消失，无任何提示。
  night_lab.gd:745 `_invalidate_pending_shelf()` 只 `note_card.visible=false`（注释承认是防刷分设计）。
- 影响: 研究者拿 84 分后想"微调糖度再试试"，回头发现 84 分没了，容易误判为 bug。
- 修复: 作废时在反馈流插入一行「配方已修改，原 品质84 分作废」，或便签淡出前显示原因。

### 2. 打磨 · 定级阈值（88/78/62）全程不可见
- 证据: p5_mktf.png — 三卡给出「爆款·均分92·菜单价19 / 普通·均分69·菜单价12 / 滞销·未上架·灵感+3」，但没有任何地方说明 88/78/62 这三档线（market_tests.gd:40-56）。检验中卡片也只有趋势「上涨 3」。
- 影响: 无法回答"我的 84 分还差多少到爆款"，无法规划是否再试一晚。
- 修复: 结算副标题或卡片 tooltip 列出「≥88 爆款¥18 · ≥78 招牌¥15 · ≥62 普通¥12 · 退款3灵感」。

### 3. 困惑 · 市场检验卡片不显示配方
- 证据: p5_mkt.png / p5_mktf.png — 卡片只有 名称/当晚分/第N/3晚/进度条/结论；tests 数据里明明存了 base/milk/toppings/sugar（night_settlement_panel.gd `_result_card` 未渲染）。
- 影响: 三晚后想复盘"哪个公式拿到哪个档"，只能靠记忆。
- 修复: 名称下加一行小字公式（茶底×奶基+小料）。

### 4. 打磨 · 缺"今晚最佳/每公式最佳分"
- 证据: p5_night.png — 右侧反馈流只增不减且自动滚到底（`_scroll_feedback_to_end`），试错十几次后早期高分被冲走；没有任何「今晚最佳 87（红茶×鲜奶+布丁）」汇总。
- 影响: 研究型玩家最想要的基准线不存在，重复试同一公式无法对比。
- 修复: 反馈区顶部钉一行"今晚最佳分+公式"；或便签卡记录该公式历史最高。

### 5. 打磨 · 灵感不足时试做钮只置灰、无解释
- 证据: night_lab.gd:804 `try_btn.disabled = budget < 2`；按钮无 tooltip（缺料有 NIGHT_INCOMPLETE 提示，缺灵感没有）。
- 影响: 半夜灵感耗尽=硬停机，不知道"收工后留存会不会亏"。
- 修复: 置灰时 tooltip「灵感不足（试做需2点）；收工时未用灵感退回留存」。

### 6. 打磨 · 顶栏「今晚 16 · 留存 10」双数字不自解释
- 证据: p5_night.png 顶栏胶囊；机制藏在 NIGHT_BUDGET_TOOLTIP 悬停里（"每晚最多装入 N 点活跃灵感；收工退回留存"）。
- 影响: 第一晚分不清哪个是可花额度、留存会不会浪费，不敢花。
- 修复: 胶囊常显微标签（如「今晚可花 16 / 留存 10」）或首晚一次性气泡教学。

### 7. 打磨 · 命中已知传说配方时不给品质分
- 证据: night_lab.gd `_on_try` 命中分支只报「传说配方诞生/重复」，不追加 NIGHT_QUALITY_SCORE；只有未命中才显示「◎ 优秀（品质分 N）」。
- 影响: 想对比"经典珍珠到底多少分"的研究者拿不到数据，反馈体感不一致。
- 修复: 命中分支同样附上品质分一行。

### 8. 打磨 · 黑暗槽位管理入口藏在「明日主推菜单」里
- 证据: p5_darkboard.png（黑暗槽位板，每槽 猎奇价/成交杯数/替换/下架，替换横幅「新候选…请选择要替换的槽位」本身清楚）；但入口按钮文案是「主推 0/3 · 热卖 0」（NIGHT_MENU_PILL），不含黑暗字样；翻车实验还会被自动装槽（NIGHT_DARK_MENU_ADDED 仅日志一行）。
- 影响: 新玩家不知道去哪管理黑暗槽；自动占槽不点头。
- 修复: 主推胶囊加黑暗槽计数（如「黑暗 2/3」）；自动装槽时弹同款替换板让玩家确认或跳过。

## 亮点

### S1. 线索体系分层且不剧透，正是研究玩家想要的
图鉴未解锁项给"传闻"谜语（「炭焙茶香里藏着一份嫩黄甜品」→乌龙+布丁，p5_book.png），未到解锁日显示「第 N 天将解锁更多相关原料」；试做反馈另有 换一种【小料】/甜度不对/就差一口气 三级逼近线索 + 相性图鉴配对发现。难度曲线拿捏得好。

### S2. 研究单与三晚市场检验的状态可读性佳
研究单卡片 GOLD 活跃→MINT 完成、标题变「已完成·已领取 +2」、反馈流追加「研究单完成·灵感+2」；检验卡「第N/3晚+进度条+均分+上涨/回落/持平+明晚继续检验」，最终卡档位/菜单价/退款一次性讲清（p5_mkt.png / p5_mktf.png / p5_brief.png）。
