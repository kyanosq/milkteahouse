# P6 压力操作位试玩 · 第12+天 / 合约 / 店员 / 高峰队列

日期 2026-08-15 · 证据：/tmp/p6_*.png（截图）、/tmp/p6_bot.log、/tmp/p6_bot2.log（机器人）
视角：后期高压店主——同时盯 3 张订单卡、合约进度、店员工资、账本。

## 发现（按严重度）

### 1.［崩溃感·工具链］指定的压测机器人命令必然断言崩溃
- 证据：`BOT_DAY=12 BOT_CONTRACT=revenue_sprint` → `res://tests/autoplay.gd:84` 断言失败即退（/tmp/p6_bot.log 仅一条 SCRIPT ERROR，无 [RESULT]）。原因：合约首个目标日为 16（autoload/endless_contracts.gd:5），且 sign_contract 还要求金币 ≥ 签约费（:117、:124），机器人默认金币 0。
- 修复：autoplay 里 `target_day = max(16, BOT_DAY)` 并在签约前补足金币；或签约失败时打印明确原因并以非零码退出，而不是裸断言。

### 2.［困惑·工具链］截屏脚本互斥开关被静默吞掉，三张"不同"截图字节级相同
- 证据：`SHOT_UPGRADES=1` 会把场景切进夜间分支（tests/screenshot.gd:69），`SHOT_REWORKED`/`SHOT_ORDER_WRONG` 被忽略——/tmp/p6_d12.png、p6_rework.png、p6_wrong.png md5 全部 = 6c0f3a60…；同理 `SHOT_NIGHT=1 + SHOT_STAFF_SHORTFALL_END=1` 拍出的是夜间实验室而非欠薪结算（夜间分支无该处理器，screenshot.gd:143-241）。
- 修复：环境变量组合冲突时 print 警告或直接 fail-fast；文档标注互斥矩阵。

### 3.［困惑］HUD 顶部是"营收数字汤"，高压下 346/368/497/515 四个数格式雷同
- 证据：/tmp/p6_active.png：一枚胶囊塞下 `第16天·118s 346/368·3★需515`（day_shop.gd:2723-2724），旁边合约胶囊再给 `营收 346/497`（12px 灰字、还会截断省略，day_shop.gd:359-366、:2740）。三个"当前营收"各自独立，扫一眼分不清哪个对应合约。
- 修复：时间独立成胶囊；"当前营收"数字在目标条与合约胶囊里共用同色高亮；合约胶囊用合约色 D99A43 区分。

### 4.［困惑］小费档位完全不可预判，出杯前没有任何卡面提示
- 证据：小费 3/1/0 与耐心档共用 0.7/0.4 阈值（day_shop.gd:23 注释、:2144），但订单卡上只有变色的耐心秒数（PATIENCE_BAND_COLORS，:24、:242），"这单还能拿多少小费"只能靠脑内换算；/tmp/p6_wrong2.png 三张卡均无小费角标。
- 修复：耐心秒数旁加 `+3 / +1 / –` 小角标，或至少给耐心条加 tooltip。

### 5.［困惑］欠薪结算行太安静，结算时不解释后果
- 证据：/tmp/p6_staff2.png：`阿澄 工资实付 5/14 · 第 10 天休整` 是普通黑字混在奖励行里（DAY_RESULT_WAGE_SHORTFALL）；"今日全部员工效果暂停"要到休整日当天才说（DAY_STAFF_RESTING_STATUS），结算时刻——做决策的时刻——看不到代价与复工日。
- 修复：欠薪行升级为警示色块，同行直接写"明日员工效果暂停 · 第 X 天复工"。

### 6.［困惑］营收冲刺"签约即可入坑"，失败感不公平
- 证据：目标 = 1.35×日目标（endless_contracts.gd:92，d16 = 497）；regular 机器人 d16 96% 完美、100% 接待、0 气走也只赚 342（连 368 基础目标都差 26，仅 1★），合约判 failed、190 签约费全扣（/tmp/p6_bot2.log [RESULT]；refund 仅成功时返 68，endless_contracts.gd:189-194）。无升级店铺产出天花板 ~340，面板却不给可行性提示。
- 修复：签约面板展示"近 3 日平均营收 vs 目标"对比；或差目标 ≤10% 时退还部分签约费，避免全损。

### 7.［打磨］错料格标记太小，红色 "! n/n" 汇总成了唯一可读线索
- 证据：每格 ✓/! 角标挂在 34px 图标里（day_shop.gd:1992-1995），/tmp/p6_wrong2.png 中视觉复核都没能认出 "!"，实际可读的只有卡头红色 `! 3/5`（:2003-2006）。
- 修复：错格加粗红框或短暂闪烁一次，扫读时先落眼到具体格子。

### 8.［打磨］崩盘日文案不升级：8 人气走 + 欠薪仍报"还在热身"
- 证据：/tmp/p6_staff2.png：served 0 / 气走 8 / 工资短缺，标题仍是青色鼓励语"还在热身，明天再来"，`流失 8` 是 13px 灰字。
- 修复：angry ≥ 5 或欠薪时切换红色警示标题，损失数字同步加重。
