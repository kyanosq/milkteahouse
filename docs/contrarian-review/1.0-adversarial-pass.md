## Findings

### S3: Frozen reset-confirm window survives across days
- Evidence: `day_shop.gd` `_process` early-returns when `not running`, so `_reset_confirm_left` stops expiring the moment a shift ends; `_start_day` did not clear it. An armed 2s window frozen at day end could persist into the next day's opening seconds.
- Impact: near-unexploitable timing edge (the player would need ≥3 coins of cup built within the frozen remainder), but a real cross-day state leak in a brand-new mechanism.
- Fix direction (applied): `_reset_cup()` zeroes `_reset_confirm_left`, covering `_start_day`, deliveries and every system-level cup clear. Pinned in operating_cost_check (arm → system reset → disarmed).
- Confidence: high (code-verified).

### S3: Tutorial replay during an event briefing buries the tutorial
- Evidence: `event_overlay` is parented to the scene root after `ui_frame`, so it renders above the tutorial overlay. Opening pause during a briefing (newly allowed in Iteration 59) exposes "Replay Tutorial", which started the tutorial *under* the briefing scrim — invisible cards, focus chaos, and a running-clock path via `_on_tutorial_finished` on finish.
- Impact: broken flow on a narrow but reachable path (briefing → Esc → Replay Tutorial); regression-class risk introduced by the same session's pause change.
- Fix direction (applied): `_replay_tutorial` dismisses a visible briefing before starting the replay (the player explicitly chose to leave it). Pinned in onboarding_check (briefing visible → replay → briefing gone, tutorial up, clock frozen).
- Confidence: high (code-verified; stacking verified visually via the new `SHOT_EVENT_PAUSE` capture showing the pause panel correctly above the briefing).

### Process finding: Iteration 59's "CJK leak on EN" claim was a false positive
- Evidence: pre-change ui.csv already carried the value-as-key row `跳过教学 → Skip Tutorial`; Godot's auto-translate localized the hard-coded literal all along. The prior audit's "zero CJK on EN" claim was correct.
- Impact: documentation accuracy only. The styling fix (secondary Skip vs primary Next) and the explicit `TUTORIAL_SKIP` key remain real improvements.
- Fix direction (applied): correction note appended to the Iteration 59 entry; the redundant value-as-key row is retained as harmless duplicate coverage.
- Confidence: high (CSV history verified via `git show 83d4415^`).
