# Coral Mint V3 UI assets

Runtime-optimized RGBA copies. High-resolution sources and the existing ingredient/HUD icon set live in
`design/mockups/coral_mint/full-set-v3/assets-transparent/`.

Generation mode: built-in ImageGen, reference-guided from `01-day-shop.png`. The prompt family requested
warm cream paper, coral/mint/cocoa outlines, low-gloss flat hand painting, empty text-free nine-patch frames,
and a solid steel-blue matte. FFmpeg color-keying produced the final transparent alpha.
